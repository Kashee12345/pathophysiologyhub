# Pathophysiology Hub — Dr. Akash Garg

A free, interactive pathophysiology study resource by **Dr. Akash Garg** (Dr. Garg Learning).
*(An independent study resource.)*

**Live site:** https://kashee12345.github.io/pathophysiologyhub/

## What's inside
- **The Interactive Body** — 86 hands-on, animated lessons across every body system (`index.html`, `lessons.html`, `weeks.html`, `interactive-body.html`)
- **Interactive book** — *Pathophysiology: A Student-Friendly Guide*, 13 chapters with figures, embedded interactives, flashcards and self-checks (`book/`, landing page `library.html`)
- **Games** — The Chase, PathoQuest, Medical Mystery (`games/`)
- **Flashcards** — 900+ cards with spaced-repetition self-grading (`flashcards.html`)
- **Exam Prep HQ** — exam simulator, ABG trainer, mechanism chains, lab-signature drill, red-flag triage, "which is it?" discriminator, cram sheet (`exam-suite/`)
- **Study guides** — six unit-exam guides plus a cumulative final, HTML + PDF (`study-guides/`)

Figure credits: `book/_credits.html`. Everything is static HTML — no build step, no login, no tracking.
