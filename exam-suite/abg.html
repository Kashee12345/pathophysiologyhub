The four-step method & normal ranges
1. Look at pH. Below 7.35 = acidosis. Above 7.45 = alkalosis. In range with abnormal values = fully compensated (use which side of 7.40 it sits on).
2. Look at PaCO2. If it moves opposite to pH, the problem is respiratory.
3. Look at HCO3. If it moves the same direction as pH, the problem is metabolic.
4. Assess compensation. Other value normal = uncompensated. Other value abnormal but pH still off = partially compensated. pH back in range with both abnormal = fully compensated.
ROME — Respiratory Opposite, Metabolic Equal.
Normals: pH 7.35–7.45 · PaCO2 35–45 mmHg · HCO3 22–26 mEq/L · PaO2 80–100 mmHg
